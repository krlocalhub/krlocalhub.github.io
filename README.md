# 김천현 · 지식서비스산업

**사이트 주소: https://krlocalhub.github.io**

천 번의 생각으로, 하나의 가치를 만듭니다.

김천현은 블로그·홈페이지·웹서버·맞춤형 프로그램·업무 자동화까지, 사업에 필요한 기술을 직접 만드는 지식서비스산업 사업자입니다.

## 하는 일

- **블로그 제작**: 회사소개, 서비스 안내, 상담 연결까지 블로그 하나로 홈페이지처럼 씁니다.
- **홈페이지 제작**: 회사·브랜드·서비스 소개와 상담 연결. 이용하기 편한 구성까지.
- **웹서버 구축**: 용도에 맞는 서버를 세우고 설정합니다. 이전과 유지보수도 맡습니다.
- **맞춤형 프로그램 개발**: 기존 소프트웨어로 안 되는 일을 업무 방식에 꼭 맞게 만듭니다.
- **업무 자동화**: 반복 입력과 정리를 줄입니다.
- **소프트웨어 판매**: 사무 환경에 맞는지 함께 확인하고 제공합니다.
